# Chapter 04: Operators in Python

## Chapter Overview

Python-এ Operators ব্যবহার করে Arithmetic Calculation, Value Comparison, Logical Decision, Variable Assignment এবং Bit-Level Operation করা হয়।

এই Chapter-এ Basic থেকে Advanced Level পর্যন্ত Python Operators শেখা হবে।

## Learning Objectives

এই Chapter শেষে তুমি পারবে:

- বিভিন্ন ধরনের Python Operators চিনতে।
- Arithmetic ও Comparison Operations করতে।
- Logical Conditions তৈরি করতে।
- Assignment Operators ব্যবহার করতে।
- Identity ও Membership Operators-এর পার্থক্য বুঝতে।
- Bitwise Operators-এর কাজ বুঝতে।
- Operator Precedence ও Associativity অনুসরণ করতে।
- Expressions-এর Result নির্ণয় করতে।
- Operators ব্যবহার করে বাস্তব Problem Solve করতে।
